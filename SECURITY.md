# Security Policy

## Supported Versions
| Version | Supported |
|---|---|
| 0.x (main) | Yes |
| older branches | No |

## Reporting a Vulnerability
1. Do not open a public issue for security vulnerabilities.
2. Send a private report to the repository owner with:
   - impact
   - reproduction steps
   - possible fix
3. Expect acknowledgement within 72 hours.

## Disclosure Process
1. Triage and reproduce issue.
2. Prepare patch on private branch.
3. Release fix and publish advisory summary.

## Scope notes
This project handles ecommerce and admin routes. Security issues affecting:
1. authentication/session
2. admin authorization
3. data exposure
4. dependency vulnerabilities
must be reported immediately.
