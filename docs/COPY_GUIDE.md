# LOVAPE - Copy Guide (Etape 0)

## 1) Voix editoriale
1. Ton: clair, sobre, utile, non dramatique.
2. Style: phrases courtes, vocabulaire accessible.
3. Priorite: information avant persuasion.
4. Jamais de promesse medicale.

## 2) Mentions obligatoires
Ces textes doivent etre visibles sur les zones cles (header/footer/checkout/fiches):
1. "Vente interdite aux mineurs."
2. "Si vous ne fumez pas, ne vapez pas."
3. Disclaimer guide: "Contenu informatif, non medical."

## 3) Lexique recommande
1. Utiliser "demande de commande" (pas "achat instantane").
2. Utiliser "materiel MTL" (pas "pod", pas "puff").
3. Utiliser "bon usage" (pas "performance extreme").

## 4) Mots/angles interdits
1. "offre explosive", "dernieres minutes", "stock presque epuise" (pression).
2. "detox miracle", "garanti sans risque" (medical trompeur).
3. "pod", "puff", "jetable", "disposable" (produits interdits).

## 5) Microcopy UI (base)
### Boutons
1. `Ajouter au panier`
2. `Envoyer ma demande`
3. `Retour au catalogue`
4. `Voir les details`

### Formulaires
1. Placeholder email: `vous@exemple.com`
2. Aide message checkout:
   - "Nous vous recontactons pour valider disponibilite, livraison et details."
3. Validation:
   - "Ce champ est obligatoire."
   - "Format invalide. Exemple: vous@exemple.com"

### Confirmation demande
1. Titre:
   - "Demande de commande envoyee"
2. Texte:
   - "Notre equipe revient vers vous avec les prochaines etapes."

## 6) Messages d'erreur recommandes
1. Erreur reseau:
   - "Une erreur reseau est survenue. Reessayez dans quelques instants."
2. Erreur validation:
   - "Certaines informations sont incompletes. Verifiez les champs signales."
3. Erreur politique produit:
   - "Ce type de produit n'est pas autorise sur LOVAPE."
4. Erreur admin login:
   - "Connexion impossible. Verifiez vos informations."

## 7) Garde-fous legaux et conformite
1. Toute page produit affiche au moins un avertissement legal.
2. Aucun wording qui banalise l'usage chez non-fumeurs.
3. Aucune promesse de sante.
4. Contenu guide: informatif, prudent, sourcable.

## 8) SEO editorial (sobre)
1. Titres pages descriptifs et factuels.
2. Meta descriptions informatives, sans clickbait.
3. Maillage interne logique vers guide, livraison, retours, contact.
